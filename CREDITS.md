# Credits

## Inspiration

**Magic Aura** was inspired by **Nimbus: Scene Atmosphere** — a scene-atmosphere plugin for **Tavo**.

We liked the *idea*: weather and mood living above the chat instead of inside the message flow. That is where the similarity ends.

Everything in this repository — the engine, the scenes, the rendering approach, the interface, the palette, the icons, the code — was written from scratch for SillyTavern.

**No code, textures, sounds, shaders or other assets from Nimbus are used, copied or redistributed here.** Nothing was decompiled or lifted; the plugin was studied only as a reference for what a user might expect from such an extension.

Magic Aura is not affiliated with, endorsed by, or connected to Tavo or the Nimbus authors.
