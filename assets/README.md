# assets

Сюда кладутся PNG-текстуры с альфой (1024×1024), которые подключаются как оверлеи:

- `frost.png` — иней по краям
- `glass-drops.png` — капли на стекле
- `grain.png` — зерно плёнки (tileable)
- `paper.png` — мятая бумага
- `vignette.png` — виньетка (если не хочется CSS-версии)

Пока папка пустая: все сцены работают на CSS-градиентах и процедурном зерне.
